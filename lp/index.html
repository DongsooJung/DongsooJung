❓ 자주 묻는 질문

상담 전 많이 주시는 질문을 정리했습니다. 추가 문의는 쇼핑몰 1:1 게시판에서 가능합니다.

🎯 KOI(수학·정보올림피아드) 준비는 몇 학년부터 가능한가요?

초등 5학년부터 가능합니다. 저학년은 사고력 수학 → 알고리즘 사고 → 코드 구현 3단계 로드맵으로, 고학년·중등은 USACO Bronze~Silver + KOI 기출 중심으로 운영합니다. 정동수 강사는 시·도 정보올림피아드 대상 수상자이며, 실제 KOI·USACO 지도 경력이 있습니다.

🏫 과학고·영재학교 입시 대비는 어떤 학생이 적합한가요?

중1~중3 전 과정을 대상으로 합니다. 특히 대구과학고등학교 17기 졸업 + 서울대 만 17세 최연소 입학이라는 드문 이력을 바탕으로 KMO·올림피아드·자소서·면접까지 통합 지도가 가능합니다. 첫 상담 때 최근 성적표·학종 기록을 지참해 주시면 정확한 진단이 됩니다.

🤖 AI 실무 교육은 비전공자도 따라갈 수 있나요?

네. 교재는 파이썬 기초 → LLM API 호출 → RAG → 에이전트 자동화 순으로 설계되어 있으며, 사전 지식이 없어도 8주 안에 실무 프로젝트 1개를 완성합니다. 서울대 박사(스마트도시공학) 과정에서 다룬 실제 연구·산업 사례를 수업 케이스로 사용합니다.

💳 수강료 결제는 어디서 하나요? 환불은 가능한가요?

모든 결제는 본 랜딩페이지가 아닌 공식 쇼핑몰(stargateedu.co.kr)에서 이루어지며, cafe24 안전 결제(PG)를 사용합니다. 전자상거래법에 따른 청약 철회·환불 규정을 준수하며, 세금계산서·현금영수증 발행이 가능합니다.

📍 수업 장소는 어디인가요? 온라인 수업도 되나요?

오프라인은 대치동 전용 스튜디오에서, 온라인은 Zoom + 공유 IDE(VS Code Live Share) 기반으로 진행합니다. 지방·해외 거주 학생도 동일 커리큘럼으로 수강 가능합니다.

🔐 개인정보·성적 데이터는 어떻게 관리되나요?

학생 성적·상담 기록은 Stargate Corp 내부 Private 저장소(2FA + Cloudflare Access 인증)에서만 접근 가능하며, 외부 인덱싱이 차단되어 있습니다. 자세한 정책은 쇼핑몰 하단 개인정보처리방침을 참고해 주세요.
