# Data

| 경로 | 설명 |
|------|------|
| `sample/` | API 키 없이 대시보드 데모용 CSV (`python scripts/make_sample.py`) |
| `raw/` | 실 API 수집 결과 (gitignore) |

샘플 파일:

- `court_auction.csv` — 법원 경매 물건
- `public_molit.csv` — MOLIT 아파트 실거래
- `exchange_rate.csv` — USD/EUR/JPY/CNY
- `companies.csv` — DART 스타일 기업 재무 요약
